One-Time Secret Setup

Add the bot token to Vercel

Create the Discord application/bot first, then add its token directly to the EFL Vercel project as an encrypted environment variable named DISCORD_BOT_TOKEN. Do not paste the token into chat, GitHub, or this page.

1. Create the Discord applicationName it EFL Commissioner (or EFL Commissioner Bot), then create its bot user.
2. Copy the bot tokenKeep it private. A Discord bot token authenticates the bot and should be handled like a password.
3. Vercel → Project Settings → Environment VariablesAdd DISCORD_BOT_TOKEN to Production, then redeploy the site.
